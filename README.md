# Boat Sales Analysis

A data analysis project focused on understanding boat sales trends, pricing patterns, and market behavior using a public dataset from Kaggle.

## Project Overview

This repository analyzes boat sales data to uncover:
- the most common and most expensive boat types
- sales trends over time
- price variation by brand, region, and category
- patterns that may influence demand and purchasing decisions

The objective is to perform exploratory data analysis (EDA), visualize insights, and summarize business-relevant findings from the dataset.

## Dataset

Source: Kaggle - Boat Sales Analytics Dataset by Arjun Gupta

Dataset link:
https://www.kaggle.com/datasets/arjunguptadatanalyst/boat-sales-analytics-dataset-arjun-gupta?select=Sales_Data.csv

This project uses the `Sales_Data.csv` dataset, which contains records relevant to boat sales analysis.

1. Load the dataset
2. Clean and validate the data
3. Explore missing values and data types
4. Analyze sales distribution, pricing, and category trends
5. Create visualizations
6. Summarize key business insights

## Possible Research Questions

- Which boat type has the highest average price?
- Which regions show the strongest sales activity?
- Are there seasonal trends in demand?
- How do prices vary across brands and boat categories?
- What factors are associated with premium sales?

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Prashantsingh8055/Boat-Sales-Analysis-.git
cd Boat-Sales-Analysis-
```

Create a virtual environment and install dependencies:

```bash
python -m venv .venv
source .venv/bin/activate   # Linux/macOS
# .venv\Scripts\activate  # Windows
pip install pandas numpy matplotlib seaborn jupyter
```

## Usage

Open the project in Jupyter Notebook or run analysis scripts after loading the dataset from the `DataSet/` folder.
